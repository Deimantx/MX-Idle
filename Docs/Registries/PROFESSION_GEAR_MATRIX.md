# Profession Gear Matrix

**Status:** Canonical ownership matrix v1.0

The shared shell is **Tool, Head, Body, Legs, Hands, Feet, Ring, Necklace**. A profession may not fill every slot at every tier. Gear effects and stats remain in the owning profession document.

| Profession | Primary Tool owner | Structural / multi-profession contract | Gear / jewelry owner |
|---|---|---|---|
| Mining | Smithing (metal Pickaxes); T0 Worn Pickaxe starter | Previous Pickaxe + tier metal + Utility Blank | Mining |

## Common physical Tool upgrade contract

Where a profession table labels Smithing as source, Smithing must contain the producer recipe. Standard pattern: prior Tool + current-tier metal component + matching-tier Utility Blank → upgraded Tool. Kits are explicit multi-profession assemblies as above. Old Tools have no durability and can be assigned to workers when not otherwise equipped.
