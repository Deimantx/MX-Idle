# 01 — SKILLS AND PROFESSIONS BRAINSTORM

**Status:** Brainstorm / Review Draft  
**Version:** 0.2  
**Purpose:** Define the full profession ecosystem and how it connects to the separate Home / Estate / Infrastructure system, including skill identities, progression axes, interdependencies, profession equipment, mastery, facilities, automation, Chronicles, workers, and long-term relevance before detailed item/resource content is created.

---

# 1. CORE SKILL PHILOSOPHY

The main profession rule:

> **Skill level unlocks content, but skill level alone should not determine how well the player performs a profession.**

A profession can eventually be influenced by:

**Skill Level + Tool + Profession Clothes + Profession Jewelry + Mastery + Specialization + Facility + Account Unlocks**

This creates multiple parallel progression paths instead of reducing every skill to one XP bar.

Two players with the same Mining level should not necessarily perform identically.

One player may focus on:

- better tools;
- raw quantity;
- rare resource chance;
- preservation;
- mastery;
- profession gear;
- facility upgrades;
- specialized production;
- automation.

Not every skill must use every progression axis equally.

---

# 2. BASELINE PROFESSION LIST

Current baseline:

## Gathering

- Mining
- Woodcutting
- Fishing
- Farming
- Hunting
- Foraging

## Production / Processing

- Smithing
- Leatherworking
- Tailoring
- Fletching
- Cooking
- Alchemy
- Jewelcrafting
- Runecrafting

Total baseline:

**14 true professions**

## Separate Core Account System — Home / Estate / Infrastructure

The former "Construction" concept is **not a profession**.

It does not use:

- normal Skill Levels;
- profession XP;
- individual action Mastery;
- profession Specialization;
- a normal skill training loop.

Instead, it is a persistent account-wide progression system representing the player's growing home, facilities, workforce, logistics, and eventually a small personal empire.

Current long-term direction:

**House → Lodge → Manor → Estate → Late-Game Holdings**

The system grows through:

- resource investment;
- Gold;
- permanent account projects;
- facility construction and upgrades;
- Chronicles milestones;
- combat/progression requirements where appropriate;
- worker capacity;
- management unlocks.

The player does not "train Construction."

The player **builds an increasingly powerful base of operations**.

This system is one of the main bridges between professions, workers, automation, storage, projects, and late-game account progression.

---

# 3. SKILLS NOT INCLUDED FOR NOW

The following should not be part of the initial baseline unless future design proves they are necessary:

- generic Crafting;
- Enchanting;
- Excavation;
- Sailing;
- other broad expansion-style professions.

## Why No Generic Crafting?

The game already contains specialized production skills:

- Smithing;
- Leatherworking;
- Tailoring;
- Fletching;
- Jewelcrafting;
- Runecrafting;
- Alchemy;
- Cooking.

A generic Crafting skill risks becoming a dumping ground for recipes that do not have a clear identity.

The preferred rule is:

> Every crafted item should belong to a profession with a meaningful mechanical and thematic purpose.

---

# 4. EVERY SKILL MUST HAVE ITS OWN GAMEPLAY IDENTITY

A major design rule:

> **Every major profession must have at least one mechanic that meaningfully distinguishes it from other professions.**

Avoid:

**Select action → wait → receive resource**

being the complete gameplay of every skill.

The exact complexity can vary, but each profession needs its own recognizable gameplay structure.

---

# 5. INITIAL SKILL IDENTITY BRAINSTORM

| Skill | Core Identity / Unique Mechanic |
|---|---|
| Mining | Multi-stage deposits with layers/depth, changing yields, tool interaction, and deeper-stage rewards. |
| Woodcutting | Grove rotation / multiple trees or resource priorities within the same activity. Wood is also a major input for Hunting traps and estate infrastructure. |
| Fishing | Catch-pool manipulation through fishing spot, bait, tackle, and setup. |
| Farming | Plots, growth cycles, crop planning, and possible soil/rotation mechanics. |
| Hunting | Tracking/prey setup, hunting methods, traps, and carcass/resource processing. Traps can consume Woodcutting and Smithing/Fletching components. |
| Foraging | Route/focus system, wild-resource discovery, and rare natural materials that are not simply bulk farm crops. |
| Smithing | Smelting, alloy creation, and multi-stage metal production rather than only ore → item. |
| Leatherworking | Hide processing → leather grades → finished equipment and profession items. |
| Tailoring | Fibres → cloth → patterns/products, with different materials supporting different purposes. |
| Fletching | Component assembly: shafts, strings, arrowheads, bolt heads, bows/crossbows, and selected Hunting components. |
| Cooking | Meals, recipe combinations, batch cooking, and higher-level food preparation. |
| Alchemy | Ingredient properties, reagent combinations, and discovery/specialization. |
| Jewelcrafting | Gem cutting, metal setting, combat jewelry, and profession jewelry. |
| Runecrafting | Essence conversion, rune patterns, and magical resource production. |

These are direction ideas, not final locked mechanics.

Every profession should later receive its own dedicated design document.

The **Home / Estate / Infrastructure system is deliberately excluded from this profession table** because it is an account system rather than a trainable skill.

# 6. STANDARD DESIGN TEMPLATE FOR EACH PROFESSION

Every future profession document should answer:

| Field | Purpose |
|---|---|
| Core Action | What the player actually does |
| Unique Mechanic | What makes the profession different |
| Main Inputs | What the profession consumes |
| Main Outputs | What the profession produces |
| Main Consumers | Which systems use its output |
| Progression Axes | Level, tool, clothing, jewelry, mastery, facility, etc. |
| Automation Options | What can eventually be queued or delegated |
| Worker Role | What workers may eventually perform |
| Long-Term Role | Why the profession still matters in late/endgame |
| Old-Tier Relevance | How previous materials remain useful |
| Chronicles Role | What account goals introduce and guide this profession |

# 7. PERSONAL ACTIVITY SLOT

A strong candidate rule:

> **The player normally performs one primary active profession/combat activity at a time.**

Examples:

- Mining;
- Smithing;
- Fishing;
- Woodcutting;
- Combat.

This gives workers, infrastructure, and automation much more value.

The intended progression becomes:

**I do everything → I build infrastructure → I manage infrastructure → infrastructure supports my endgame.**

## Natural Background Exceptions

Some systems may naturally progress in the background without consuming the main activity slot.

Possible examples:

- Farming crop growth;
- long Estate / infrastructure projects;
- fermentation or similar timed processes;
- certain account projects.

Exact exceptions need separate design.

---

# 8. PROFESSION EQUIPMENT

Profession progression should not rely only on tools.

Current profession loadout concept:

| Slot | Purpose |
|---|---|
| Tool | Primary profession-specific item |
| Head | Profession clothing |
| Body | Profession clothing |
| Hands | Profession clothing |
| Feet | Profession clothing |
| Ring | Profession jewelry |
| Necklace | Profession jewelry |

Exact slots are not final.

---

# 9. PROFESSION TOOLS

Tools should usually be the most skill-specific part of profession equipment.

Examples:

- Mining Pickaxe;
- Woodcutting Axe;
- Fishing Rod;
- Hunting Tool;
- Smithing Hammer;
- profession-specific instruments for other skills.

Tools should influence more than generic action speed.

Potential effects:

- action speed;
- yield;
- preservation;
- rare find chance;
- special resource rolls;
- profession-specific mechanics;
- access to higher-tier actions;
- better interaction with deeper or advanced activity stages.

---

# 10. TOOL PROGRESSION SHOULD UNLOCK MECHANICS

Avoid a progression that is only:

**Bronze Tool +2% → Iron Tool +4% → Steel Tool +6%**

Better tools can gradually add or improve mechanics.

Example Mining direction:

### Early Tool

- basic mining functionality.

### Mid Tool

- better deeper-stage performance;
- chance to preserve deposit integrity.

### Advanced Tool

- secondary mineral rolls;
- better rare resource handling;
- access to special deposit interactions.

### High-Tier Tool

- profession-defining endgame mechanics.

This principle can apply differently to every profession.

---

# 11. PROFESSION CLOTHING

Profession clothing should provide another progression path.

Possible effects:

- efficiency;
- output;
- preservation;
- mastery gain;
- special resource chance;
- action-specific mechanics;
- reduced resource consumption.

Not every piece must belong to only one skill.

## Shared Profession Clothing

Examples:

**Gatherer's Coat**

Could support:

- Mining;
- Woodcutting;
- Foraging.

**Artisan Gloves**

Could support multiple production skills.

This avoids creating hundreds of nearly identical profession armor pieces.

## Specialist Sets

Later progression can still include more expensive skill-specific profession sets.

These should provide stronger or more specialized mechanics.

---

# 12. PROFESSION JEWELRY

Profession jewelry adds another specialization layer.

Possible focus types:

- preservation;
- rare finds;
- mastery;
- action speed;
- output;
- special mechanic enhancement;
- resource conversion.

Jewelry should preferably create meaningful setup choices instead of functioning only as another source of generic percentages.

Possible items:

- Rings;
- Necklaces;
- Charms if later needed.

The relationship between combat jewelry and profession jewelry needs a later dedicated equipment brainstorm.

---

# 13. PROFESSION LOADOUTS

The player should not be forced to manually rebuild equipment every time they change profession.

Potential system:

- saved profession loadouts;
- automatically equip a profession loadout when starting an activity;
- separate combat and profession configurations;
- later facility/house upgrades may expand loadout options.

Exact behavior remains open.

---

# 14. GLOBAL PROGRESSION TIERS

Initial baseline:

**10 major progression tiers from Skill Level 1–100**

| Tier | Approximate Level Range |
|---|---:|
| T1 | 1–10 |
| T2 | 11–20 |
| T3 | 21–30 |
| T4 | 31–40 |
| T5 | 41–50 |
| T6 | 51–60 |
| T7 | 61–70 |
| T8 | 71–80 |
| T9 | 81–90 |
| T10 | 91–100 |

These ranges are structural, not strict unlock boundaries.

A tier can contain several unlocks across its level range.

Example:

### T4

- Level 31: resource;
- Level 34: recipe;
- Level 37: profession gear;
- Level 40: major tier milestone.

Tier should represent a **content family**, not one single unlock.

---

# 15. EQUIPMENT UPGRADE CHAINS

Some profession items should upgrade from previous versions instead of always being discarded.

Example:

**T4 Pickaxe + T5 Materials → T5 Pickaxe**

This can also apply to:

- profession clothing;
- jewelry;
- selected tools;
- facility equipment.

Benefits:

- old items retain value;
- progression feels continuous;
- fewer dead items;
- workers can inherit older gear.

Not every item needs to upgrade this way.

---

# 16. MASTERY SYSTEM

The game should support individual-action mastery similar in spirit to Melvor-style progression.

Each important action/resource can have:

**Mastery Level 1–100**

Example:

- Iron Ore Mastery 73;
- Coal Mastery 45;
- Mithril Ore Mastery 12.

Mastery improves the specific action.

---

# 17. MASTERY MILESTONES

Avoid mastery being only a tiny linear stat increase.

Important milestone rewards can occur at levels such as:

### Mastery 10

Small efficiency improvement.

### Mastery 25

Preservation or similar mechanic.

### Mastery 50

Profession mechanic improvement.

### Mastery 75

Rare resource / advanced benefit.

### Mastery 99 or 100

Major mastery effect.

Exact values and effects should differ by skill.

---

# 18. SKILL-WIDE MASTERY

In addition to individual action mastery, each profession can have overall mastery progression.

Therefore the system contains:

**Individual Action Mastery**

and

**Overall Skill Mastery Progression**

Skill-wide milestones may unlock:

- general efficiency;
- new profession mechanics;
- specialization features;
- profession equipment;
- facility interactions;
- advanced automation.

---

# 19. SPECIALIZATIONS

Mastery and specialization should remain separate systems.

A skill may eventually allow an active specialization.

Example Mining concept:

### Extractor

Focus on quantity.

### Prospector

Focus on rare resources.

### Deep Miner

Focus on deeper deposit stages.

Specializations should generally be:

- reversible;
- swappable;
- useful for different goals;
- planning tools rather than permanent character traps.

Later facilities or residence upgrades may unlock:

- multiple saved specialization loadouts;
- faster switching;
- more advanced profession configurations.

---

# 20. FACILITIES

Facilities should be a major profession progression axis.

They should not exist only as:

**Facility II = +5% Speed**

Instead, higher facility tiers should unlock gameplay.

Potential unlocks:

- new recipes;
- batch production;
- new processing methods;
- additional profession options;
- worker assignments;
- automation;
- advanced materials;
- higher-tier production;
- special profession mechanics.

Percentage bonuses can still exist, but they should support meaningful functional upgrades.

---

# 21. EXAMPLE FACILITY PROGRESSION

Example Forge direction:

### Forge I

- basic Smithing;
- basic bars;
- basic metal items.

### Forge II

- improved production;
- batch smelting.

### Forge III

- alloys;
- advanced recipes.

### Forge IV

- worker assignment;
- larger production capacity.

### Forge V

- advanced Smithing mechanics;
- special treatments;
- high-tier production options.

Exact tiers and functionality remain open.

---

# 23. OLD-RESOURCE RELEVANCE

Game design rule:

> **Reaching T10 should not automatically make T1–T5 resources worthless.**

Old resources should remain relevant through logical sinks.

Potential sinks:

- Home / Estate development;
- facility upgrades;
- account projects;
- worker equipment;
- Hunting traps;
- consumables;
- composite materials;
- profession gear upgrades;
- cross-tier recipes;
- maintenance or infrastructure where appropriate.

Avoid artificial recipes that exist only to destroy old resources.

---

# 24. WORKERS AND OLD RESOURCES

Workers can become a natural solution to low-tier resource farming.

Example late-game behavior:

The player no longer personally spends hours gathering Oak Logs.

Instead:

- the player focuses on advanced progression;
- a Woodcutting worker maintains Oak supplies;
- those resources feed Estate projects, facilities, Hunting traps, or other systems.

This helps old content remain useful without forcing high-level players to manually return to basic actions.

Workers are therefore not only a passive-income mechanic.

They become the mechanism through which the player's growing estate maintains the lower layers of the economy while the player pushes new content.

---

# 25. HOME / ESTATE DEVELOPMENT AS A CORE ACCOUNT SINK

The Home / Estate / Infrastructure system should become one of the largest material and Gold sinks in the game.

It is **not a skill**.

Possible requirements include:

- Stone;
- Logs;
- Bars;
- Cloth;
- Leather;
- Gold;
- special monster materials;
- profession-produced components;
- rare project materials.

The system should connect nearly the entire profession ecosystem.

The important distinction:

**Professions produce resources and equipment.  
The Estate consumes those outputs to permanently expand the account.**

The Estate should feel like the player's accumulated wealth and infrastructure made visible.

Early on this means a small home.

Later it becomes:

- specialized facilities;
- larger storage;
- worker housing;
- management rooms;
- production support;
- logistics;
- multiple worker teams;
- large permanent projects;
- eventually a small personal economic empire.

---

# 26. RESIDENCE / ESTATE PROGRESSION

Current recommended high-level progression:

**House → Lodge → Manor → Estate → Holdings**

Names can still change later.

These are not levels in a Construction skill.

They are major **account infrastructure stages**.

## House

Early personal base.

Primary role:

- first storage expansion;
- first basic facility slots;
- first planning/automation unlocks;
- introduction to account infrastructure.

## Lodge

The home becomes a functioning production base.

Primary role:

- several specialized facilities;
- first meaningful worker capacity;
- better storage/logistics;
- larger activity queues;
- more profession support.

## Manor

The player begins managing an organization rather than only a home.

Primary role:

- multiple worker teams;
- upgraded facilities;
- management/planning systems;
- worker equipment infrastructure;
- larger permanent projects;
- broader automation.

## Estate

The account now has a substantial support economy.

Primary role:

- large worker capacity;
- specialized production departments;
- advanced logistics;
- high-tier facilities;
- worker schedules;
- advanced account projects.

## Holdings

Endgame expansion beyond a single building.

The main Estate remains the player's headquarters, but the account can control additional holdings, work sites, or support locations.

This should **not turn the game into a city builder**.

The purpose is to create the feeling of a growing personal domain / mini empire while keeping the game an idle RPG.

Residence progression should unlock:

- storage;
- facilities;
- profession improvements;
- worker capacity;
- automation;
- logistics;
- account management;
- long-term projects;
- new gameplay options.

The home should represent account development, not only cosmetics.

---

# 27. LONG-TERM PROJECTS

Long-Term Projects are part of the account infrastructure layer.

They connect strongly to:

- Home / Estate progression;
- Chronicles;
- profession resources;
- facilities;
- workers;
- major account milestones.

They do not grant Construction XP because Construction is not a skill.

Example:

## Restore the Old Forge

Requirements:

- Stone;
- Iron Bars;
- Hardwood;
- Gold.

Reward:

**Forge III unlocked**

Another example:

## Expand the Storehouse

Potential rewards:

- additional storage functionality;
- worker material reserves;
- logistics options;
- automation options.

Later projects can become much larger:

- Manor wings;
- expanded Worker Quarters;
- specialized workshops;
- large storehouses;
- remote holdings;
- high-tier magical or industrial facilities.

Large projects may take days of preparation.

Their main purpose is to create clear long-term resource goals and transform accumulated materials into permanent account growth.

---

# 28. CHRONICLES

Chronicles should exist from the beginning of the game.

It should not be only a tutorial or quest journal.

Chronicles should function as:

**Tutorial + Account Roadmap + Recommended Goals + Progress Tracker**

The system should help answer:

> **What should I roughly work toward next?**

without forcing the player into a single exact route.

---

# 29. CHRONICLES STRUCTURE

Chronicles can use Chapters.

Example conceptual structure:

## Chapter 0 — First Steps

- learn Mining;
- craft first Tool;
- catch food;
- cook food.

## Chapter 1 — Self-Sufficient

- Smith first equipment;
- start Combat;
- defeat first significant enemy;
- build first House.

## Chapter 2 — Establishing a Home

- upgrade storage;
- build Workshop;
- unlock profession gear;
- start Farming.

## Chapter 3 — Expanding the Craft

- unlock more professions;
- build specialist facilities;
- complete first major project.

Later Chapters can include:

- worker teams;
- higher-tier facilities;
- major bosses;
- Manor progression;
- advanced automation;
- endgame infrastructure.

Chronicles should continue throughout the entire game.

---

# 30. CHRONICLES GOAL TYPES

Each Chapter can contain different goal levels.

## Main Goals

Important account progression milestones.

## Recommended Goals

Strong progression suggestions.

## Optional Goals

Extra objectives for completion-oriented players.

Chronicles should guide rather than act as a linear prison.

---

# 31. CHRONICLES SHOULD EXPLAIN WHY

A strong Chronicle goal should not only say:

**Upgrade your Forge**

It should also explain:

### What

Upgrade the Forge.

### Why

This unlocks Alloy Smithing.

### Suggested Path

Mining → gather ore → Smithing → Home / Estate upgrade.

This effectively gives the game an integrated progression guide.

---

# 32. CHRONICLES REWARDS

Chronicles should not become constant reward-claim spam.

Small rewards may be appropriate:

- Gold;
- basic resource packs;
- consumables;
- quality-of-life rewards.

However, the main reward should often be the progression milestone itself.

Example:

**Build House**

The important reward is:

**The player now has a House and access to its systems.**

Avoid unrelated rewards such as giving a random legendary weapon for completing a construction tutorial.

---

# 33. ACTIVITY PLANNER

The Activity Planner can become one of the defining idle systems.

Early game example:

**Mine Iron until Bank contains 2,000.**

Later:

**Mine Iron until 5,000 → Mine Coal until 2,500 → Smith Steel until 500 Bars.**

Advanced:

**If Coal < 1,000 → Mine Coal  
Otherwise → Smith Steel**

The interface should remain understandable.

Avoid turning the game into a programming language.

---

# 34. AUTOMATION PROGRESSION

Automation should improve alongside infrastructure.

Potential progression:

## Start

- one active action;
- simple quantity target.

## House

- small action queue.

## Lodge

- larger queue;
- reserve conditions.

## Manor

- cross-skill plans;
- fallback activities;
- saved planning setups.

## Estate

- worker schedules;
- advanced templates;
- broader automation control.

A stronger residence therefore improves how well the player can plan idle time rather than only giving numerical bonuses.

---

# 35. WORKERS

Workers should not magically generate resources.

They should perform actual profession activities using the same broad economic rules as the player.

Potential worker data:

- Profession;
- Proficiency;
- Tool;
- Profession Clothes;
- Profession Jewelry where appropriate;
- Assigned Facility;
- Assigned Activity;
- Efficiency;
- Production Rate.

Example:

## Miner Worker

Mining Proficiency: 42  
Tool: Steel Pickaxe  
Equipment: Miner Gloves  
Assignment: Iron Deposit  
Production: calculated Iron/hour

Exact worker rules remain open.

---

# 36. WORKER LIMITATIONS

Workers should support progression rather than replace it.

Strong candidate rules:

- the player must personally unlock content before workers can use it;
- workers cannot discover new tiers for the account;
- workers are strongest at maintaining already-unlocked economy;
- workers may be less efficient in the player's newest progression tier;
- workers gradually take over older repetitive content while the player pushes forward.

This creates a natural account evolution.

---

# 37. OLD PROFESSION GEAR CAN MOVE TO WORKERS

One strong economy loop:

The player upgrades from T5 profession equipment to T6.

Instead of salvaging all old equipment:

**T5 gear can be assigned to a worker.**

Example:

Player:
- T8 Mining setup.

Workers:
- T4;
- T5;
- T6 Mining setups.

Benefits:

- old gear remains useful;
- workers create demand for profession equipment;
- profession crafting continues to matter.

## Account-System Consumer

The Home / Estate / Infrastructure system sits **outside** the profession list and consumes outputs from many professions.

It converts:

**Resources → Facilities → Workers → Automation → Permanent Account Power**

This is deliberately different from adding another trainable profession.

## Separate Account Progression

The Home / Estate system has its own arc:

**House → Lodge → Manor → Estate → Holdings**

It progresses through permanent upgrades and projects rather than Skill Levels.

---

# 40. COMBAT ↔ PROFESSION LOOP

Combat should not exist as a separate economy.

Professions prepare the player for combat through:

- weapons;
- armor;
- food;
- potions;
- runes;
- jewelry;
- consumables;
- profession-created upgrades.

Combat returns:

- monster materials;
- rare crafting resources;
- gear;
- progression unlocks;
- special components.

Core loop:

**Professions → Combat → New Materials → Better Professions/Gear → Harder Combat**

---

# 41. COMBAT AS PREPARATION

Combat depth should come primarily from planning before an idle session.

The player chooses:

- Weapon;
- Off-Hand;
- Armor;
- Food;
- Potion;
- Runes;
- Jewelry;
- abilities;
- spells;
- special attacks;
- defensive setup;
- resistances;
- future utility systems.

Enemies can create planning problems through:

- damage type;
- defense;
- weaknesses;
- attack speed;
- status effects;
- special attacks;
- sustain pressure;
- accuracy/evasion interactions.

The interesting gameplay should largely happen before pressing **Start**.

---

# 42. COMBAT EFFICIENCY UI

The game should provide clear estimates where possible.

Possible metrics:

- Estimated Kills/hour;
- Combat XP/hour;
- Food/hour;
- Potion/hour;
- Rune or ammunition usage/hour;
- Expected Loot/hour;
- approximate Survival / Death Risk.

This supports planning-based idle combat.

---

# 43. FORAGING — CURRENT DESIGN RISK

Foraging currently has the weakest unique identity of the proposed professions.

It risks overlapping with:

- Farming;
- Woodcutting;
- Alchemy ingredient gathering.

Foraging should remain only if its gameplay becomes meaningfully distinct.

Current possible direction:

## Foraging Routes

The player chooses:

- route;
- duration;
- resource focus;
- risk/reward or efficiency preference.

Possible focus categories:

- Herbs;
- Fibres;
- Fungi;
- Wild Food;
- Resin;
- uncommon natural materials.

If Foraging eventually becomes only:

**Select Herb → wait**

then merging or removing it should be considered.

Outputs can include:

- Meat → Cooking;
- Hides → Leatherworking;
- Bones → Alchemy / other crafting;
- Sinew → Fletching;
- special animal parts → equipment and advanced recipes.

Hunting can also have a distinct gameplay identity through:

- hunting methods;
- carcass processing.

Current recommendation:

**Keep Hunting as a dedicated profession.**

# 45. LEATHERWORKING / TAILORING / SMITHING TRIANGLE

These three should remain separate instead of being merged into a generic Crafting skill.

Strong thematic structure:

**Heavy / Metal Gear → Smithing**

**Leather / Ranged Gear → Leatherworking**

**Cloth / Magic Gear → Tailoring**

All three can additionally produce profession equipment.

This gives combat archetypes clear crafting identities.

# 46. HOME / ESTATE SYSTEM AS THE CONNECTING ACCOUNT SYSTEM

The Estate is **not one skill among many**.

It is the layer that turns profession output into permanent account infrastructure.

Example:

Mining  
→ Stone / Metal

Woodcutting  
→ Wood

Smithing  
→ Fixtures / Components

Tailoring  
→ Interior Materials

Leatherworking  
→ Furnishings / Components

Alchemy  
→ Special Treatments

Runecrafting  
→ Magical Facilities

Jewelcrafting  
→ Advanced Components

Cooking / Farming  
→ Worker provisions where appropriate

Hunting  
→ specialty materials, hides, trophies, and infrastructure components

All can feed:

**House / Facilities / Workers / Estate / Holdings**

In return, infrastructure supports the rest of the game through:

- storage;
- profession facilities;
- automation;
- worker slots;
- worker logistics;
- profession bonuses;
- project unlocks;
- account management;
- passive parallel production.

This can become one of the major defining differences from a simpler Melvor-style progression model.

The intended fantasy is not:

> "I trained Construction to level 80."

It is:

> "I started with a small house and gradually built an estate with workshops, specialists, workers, logistics, and enough infrastructure to support my endgame character."

At high progression, the player should feel like they control a **small personal workforce / mini empire**, while still personally pushing the hardest content.

# 47. PROGRESSION ERAS

## Era 1 — I Do Everything

The player personally performs almost every important activity.

Main focus:

- learning systems;
- leveling professions;
- acquiring tools;
- early combat;
- first House;
- basic economy.

## Era 2 — I Build Infrastructure

The player starts investing heavily in:

- residence upgrades;
- storage;
- facilities;
- profession gear;
- major projects;
- automation.

## Era 3 — I Manage Infrastructure

Workers and advanced facilities handle selected repetitive or older economic tasks.

The player focuses on:

- planning;
- allocation;
- advanced professions;
- harder combat;
- large projects;
- optimization.

## Era 4 — Infrastructure Supports My Endgame

The player still performs the most important high-tier progression and combat.

The developed infrastructure supports:

- resource supply;
- consumables;
- older-tier materials;
- profession components;
- worker production;
- long-term projects.

Core progression identity:

**I do everything → I build infrastructure → I manage infrastructure → infrastructure supports my endgame.**

# 49. MAJOR OPEN QUESTIONS — RECOMMENDED ANSWERS

These are now filled with a recommended baseline so they can be reviewed rather than answered from scratch.

## Skill List

### Is the baseline correct?

**Recommendation: Yes, with one correction: 14 professions, not 15.**

Construction is removed from the profession count and replaced by the separate Home / Estate / Infrastructure system.

### Is any important profession missing?

**Recommendation: No additional profession should be added right now.**

The current ecosystem already covers resource gathering, food, combat supplies, heavy/leather/cloth equipment, ranged production, magic resources, jewelry, and long-term account infrastructure.

Adding more now would increase content burden before existing skills prove their identity.

### Should any profession be merged or removed?

**Recommendation: Keep all 14 for now.**

Foraging is the only skill that still needs to prove its identity, but it should remain during the next design pass.

### Does Construction belong fully in the main skill list?

**No.**

It is now explicitly an account-wide Home / Estate / Infrastructure system.

---

## Personal Activity

### Should the player always have exactly one main activity?

**Recommendation: Yes.**

One player-controlled activity at a time creates meaningful opportunity cost and makes workers/infrastructure valuable.

### Which systems are allowed to progress in parallel naturally?

Recommended exceptions:

- Farming crop growth;
- workers;
- Long-Term Projects;
- facility processes specifically designed as timed background processes;
- passive residence/account timers;
- other explicitly asynchronous systems added later.

Normal gathering, production, and Combat do not run simultaneously for the player.

### Does Combat use the same personal activity slot?

**Recommendation: Yes.**

If the player is fighting, they are not simultaneously personally Mining or Smithing.

Workers and background systems can continue.

---

## Profession Gear

### Are Head / Body / Hands / Feet the correct clothing slots? Should Legs exist?

**Recommendation: Tool + Head + Body + Legs + Hands + Feet + Ring + Necklace.**

Legs should be included so profession clothing mirrors the familiar full equipment structure.

### Should all professions use the same clothing layout?

**Recommendation: Use the same UI/loadout shell, but do not force every profession to have a unique item in every slot at every tier.**

This keeps the system understandable without creating unnecessary content bloat.

### Should profession Ring / Necklace use separate loadouts from combat gear?

**Recommendation: Yes.**

Profession loadouts should be separate saved configurations.

The physical item types may still overlap with combat items, but changing profession should not require manual gear swapping.

### How many shared sets versus skill-specific sets?

Recommended structure:

- early game: broad shared sets such as Gatherer / Artisan;
- midgame: category sets plus selected profession-specific pieces;
- late/endgame: more specialized profession sets and jewelry.

Do not create a full unique 8-piece set for every profession at every tier.

---

## Tools

### How much tool progression should be numerical versus mechanical?

**Recommendation: Every tool tier can improve numbers, but major tool milestones should add or improve mechanics.**

Example structure:

- every tier: better baseline performance;
- every few tiers: meaningful mechanic upgrade;
- high tiers: profession-defining interaction.

### Do all professions require a tool?

**Recommendation: No.**

Every profession needs a progression anchor, but that does not always need to be a handheld tool.

Gathering professions usually use tools.

Some production professions can rely more heavily on facilities, benches, profession clothing, recipe systems, or specialized implements.

Do not invent a pointless tool only for symmetry.

### Should tools have durability?

**Recommendation: No durability.**

Tools are permanent equipment until replaced/upgraded.

Routine durability repair would add maintenance friction without improving long-idle planning.

---

## Mastery

### Exact Mastery cap

**Recommendation: 100 Mastery per important action/resource.**

### Exact milestone structure

Recommended major milestones:

- 10;
- 25;
- 50;
- 75;
- 100
- 

Small scaling can occur between milestones.

### Should Skill-Wide Mastery unlock permanent mechanics?

**Recommendation: Yes.**

Potential rewards include loadout options, improved profession mechanics, specialization features, automation features, facility interactions, and quality-of-life.

### How quickly should Mastery progress?

**Recommendation: Slower and broader than normal Skill Level progression.**

A player can reach Skill Level 100 while still having a large amount of Mastery progression remaining.

This creates meaningful post-100 profession development without immediately increasing the skill cap.

---

## Specialization

### At what point are specializations unlocked?

**Recommendation: Around T4 / approximately Skill Level 30–40.**

The player should first understand the base profession before choosing optimization directions.

### How often can they be switched?

**Recommendation: Freely switch outside the current action.**

No permanent choice and no punitive respec fee.

Changing specialization while training should stop/restart the current action cleanly.

### Do facilities improve specialization systems?

**Recommendation: Yes, mainly through flexibility rather than raw stacking power.**

Facilities can unlock saved specialization presets, additional options, faster setup switching, and profession-specific interactions.

---

## Facilities

### Exact number of facilities

**Recommendation: Start with roughly 10–12 major facility families, not one room per recipe.**

Current strong candidates:

- Workshop;
- Forge;
- Tannery;
- Textile Room;
- Kitchen;
- Greenhouse / Herbarium;
- Alchemy Lab;
- Fletcher Bench;
- Jeweler Bench;
- Runic Study;
- Storehouse;
- Worker Quarters;
- Planning / Management Office.

Some can later merge if the UI becomes too fragmented.

### Facility tier count

**Recommendation: 5 major facility tiers.**

Five tiers are enough to provide meaningful jumps without turning every room into another 1–100 grind.

### Which facilities support multiple professions?

Strong multi-profession facilities:

- Workshop;
- Greenhouse / Herbarium;
- Storehouse;
- Planning Office;
- Worker Quarters.

Specialist facilities primarily support one production profession.

### Which facility upgrades are required versus optional?

**Recommendation: Split upgrades into Core and Specialization branches.**

Core facility upgrades unlock major functionality required for progression.

Optional upgrades improve efficiency, automation, worker use, specialization, or quality-of-life.

---

## Chronicles

### Chapter count

**Recommendation: Prologue + approximately 10 major Chapters, loosely aligned with the 10 broad progression tiers.**

They do not need to map 1:1 to skill levels.

### Main / Recommended / Optional goal balance

Per Chapter, target roughly:

- 3–5 Main Goals;
- 4–8 Recommended Goals;
- optional goals as needed.

Avoid giant checklists.

### Reward philosophy

**Recommendation: The unlock itself is usually the main reward.**

Small rewards can include Gold, starter resources, consumables, or convenience unlocks.

Avoid unrelated power spikes.

### How much future content should Chronicles preview?

**Recommendation: Fully show the current Chapter and next Chapter.**

Later Chapters can show titles / broad hints without exposing every future requirement.

### Should some goals gate progression?

**Recommendation: Usually no.**

Actual progression should mostly be gated by skill levels, bosses, resources, facilities, and account milestones.

A few very early tutorial steps can gate UI/systems to prevent confusion, but Chronicles later becomes guidance rather than a prison.

---

## Activity Planner

### Which rules exist from the beginning?

Recommended starter rules:

- continue indefinitely;
- stop at item quantity;
- stop at Skill Level;
- stop when input runs out.

No multi-step queue at the very beginning.

### Which conditions require infrastructure upgrades?

Suggested progression:

**House**
- short queue;
- simple quantity targets.

**Lodge**
- larger queue;
- resource reserve conditions.

**Manor**
- cross-profession plans;
- fallback actions;
- saved templates.

**Estate**
- advanced worker schedules;
- conditional templates;
- large planning capacity.

**Holdings**
- empire-scale production schedules and department-level planning.

### Maximum queue length

Recommended starting targets:

- House: 2 steps;
- Lodge: 4;
- Manor: 6;
- Estate: 10;
- Holdings: expanded / specialized queues rather than simply unlimited.

Exact numbers remain balanceable.

### Resource reserve logic

The player can define a protected minimum.

Example:

> Never consume Coal below 1,000.

Player actions, planner actions, and workers should respect the reserve unless explicitly overridden.

### Failure / fallback behavior

Recommended order:

1. try current action;
2. if impossible, use configured fallback;
3. otherwise move to the next eligible queued action;
4. if nothing can run, pause and report why.

Never silently destroy or bypass player reserves.

---

## Workers

### Worker capacity progression

Recommended target scale:

**House**
- 0–1 helper / introduction.

**Lodge**
- roughly 2–4 workers.

**Manor**
- roughly 6–10 workers.

**Estate**
- roughly 15–25 workers.

**Holdings / Endgame**
- 30+ workers across specialized teams, expandable if the system remains readable.

The exact numbers can change, but endgame should genuinely feel like a small workforce / mini empire.

### Worker proficiency progression

**Recommendation: Workers gain profession-specific Proficiency from doing work.**

They do not need the player's full Mastery system.

### Do workers gain their own levels?

**Recommendation: Yes, but simplified.**

A worker can have:

- profession;
- proficiency rank/level;
- specialization/role;
- equipment;
- assignment.

Avoid giving every worker a full player-style character sheet.

### Do workers use full profession equipment?

**Recommendation: Yes, but management must be streamlined.**

Use:

- equipment templates;
- auto-equip rules;
- team loadouts;
- bulk assignment.

This keeps old profession gear useful without forcing the player to manually manage dozens of characters piece by piece.

### Wages / food / housing / upkeep

Recommended model:

- **Housing is mandatory capacity.**
- Worker recruitment and promotion can cost Gold/resources.
- Ongoing food/provisions can improve or sustain efficiency.
- Avoid harsh continuous wages that constantly punish the player.
- If provisions run out, workers slow/pause rather than permanently disappear.

This creates economic demand without turning workers into chores.

### How much weaker should workers be in the newest tier?

**Recommendation: Workers are primarily an economy-maintenance layer.**

Baseline rule:

- normal workers operate best on previously established tiers;
- the player's newest tier is mainly pushed personally;
- advanced specialist workers can eventually enter the current tier at reduced efficiency.

### Can workers contribute to Long-Term Projects?

**Recommendation: Yes.**

They can contribute through gathering required resources, processing components, assigned labor/progress, and logistics.

Projects may have worker-labor slots that become more important as the Estate grows.

---

## Home / Estate / Infrastructure System

### Exact progression

Recommended current structure:

**House → Lodge → Manor → Estate → Holdings**

This is an account progression ladder, not a skill ladder.

### Does later progression expand beyond one property?

**Recommendation: One main headquarters plus later secondary Holdings.**

Do not make the player manage several identical houses.

Secondary Holdings should be specialized support sites managed through the Estate interface.

### Relationship between Construction XP and projects

**None.**

There is no Construction Skill XP.

Progress comes from completed upgrades, projects, facilities, worker capacity, residence stages, and account milestones.

### How do facilities unlock?

Recommended combination:

- required residence stage;
- resource/Gold cost;
- relevant Chronicle/account milestone;
- profession/combat requirement where logical.

Example:

A high-tier Runic facility may require both Estate capacity and meaningful Runecrafting progress.

### How large should the late-game empire layer become?

**Recommendation: Large enough to feel like an organization, not large enough to become a city-building game.**

Target fantasy:

- dozens of workers;
- several worker teams;
- specialized production departments;
- multiple facilities;
- one main Estate;
- secondary Holdings;
- large resource flows;
- advanced planner/automation;
- major permanent projects.

The player's character still personally handles frontier progression, highest-tier profession discovery, hardest Combat, major bosses, and important unlocks.

Infrastructure supports the hero; it does not replace the hero.

---

## Foraging

### Does the route/focus model create enough identity?

**Recommendation: Route/focus alone is not enough. Add Discovery.**

Foraging should combine:

- route selection;
- resource focus;
- discovery chance;
- rare wild materials;
- seed/species discovery.

### What resources are truly exclusive to Foraging?

Strong candidates:

- wild fungi;
- rare herbs;
- resins;
- unusual fibres;
- wild seeds;
- rare botanicals;
- medicinal plants;
- special natural reagents.

A useful relationship:

**Foraging discovers rare wild resources → Farming can later domesticate selected discoveries for bulk production.**

This gives both professions different jobs.

### Should it stay or merge?

**Recommendation: Keep Foraging.**

Its final identity becomes:

> **Explore abstract gathering routes, discover wild resources, and supply rare natural ingredients that Farming cannot initially mass-produce.**

If later design fails to support this distinction, merging can be reconsidered.

# 51. CURRENT DESIGN PRINCIPLE SUMMARY

The profession game should not become a collection of isolated progress bars.

The Home / Estate system should also not become another disguised profession.

The target experience is:

**Train Skills**

↓

**Improve Tools / Clothes / Jewelry**

↓

**Build Mastery**

↓

**Choose Specialization**

↓

**Invest Profession Output Into Facilities**

↓

**Complete Permanent Account Projects**

↓

**Grow House → Lodge → Manor → Estate → Holdings**

↓

**Unlock Better Automation**

↓

**Recruit, Equip, and Organize Workers**

↓

**Workers Maintain Older Economy**

↓

**Player Pushes New Skills / Combat / Tiers**

↓

**Infrastructure Supports Endgame**

The long-term fantasy is:

**I do everything → I build infrastructure → I manage infrastructure → I command a workforce → my infrastructure supports my endgame.**

The goal is a large idle RPG where the account becomes progressively more capable not only because numbers become larger, but because the player builds an increasingly sophisticated economic system around the character.

At the beginning, the player is one person with almost nothing.

At the end, the player is still the central character pushing the hardest progression, but now stands at the center of a developed Estate, specialized facilities, large stores of resources, multiple worker teams, and a small personal economic empire.
